ساخت بات در تلگرام (BotFather)

⏱ ۵ دقیقه

بات‌های تلگرام همه از طریق ربات رسمی B BotFather ساخته می‌شوند:

  1. در تلگرام به @BotFather پیام بدهید
  2. دستور /newbot را بفرستید
  3. یک نام نمایشی برای بات انتخاب کنید (مثلاً «بات خبر من»)
  4. یک یوزرنیم یکتا انتخاب کنید که حتماً به bot ختم شود (مثلاً my_news_helper_bot)
شبیه‌ساز گفتگو
/newbot
Alright, a new bot. How are we going to call it? Please send me the name.
بات خبر من
Good. Now let's choose a username (must end in 'bot').
my_news_helper_bot
Done! Use this token: 7216…:AAF…
⚠️ توکن را کپی و در جای امن نگه دارید
⚠️
توکن = کلید بات شماهر کسی توکن را داشته باشد کنترل بات را دارد. آن را در گیت، اسکرین‌شات یا جایی عمومی منتشر نکنید. اگر لو رفت: BotFather → /revoke
💡
اختیاری ولی پیشنهادی: دستورات بات را با /setcommands ثبت کنید. محتوای آماده در فایل BOTCOMMANDS.txt ریپو هست — کافیست محتوایش را برای BotFather بفرستید تا منوی دستورات کاربران فعال شود.

ساخت دیتابیس در Supabase

⏱ ۵ دقیقه

بات برای ذخیره کاربران، منابع خبری، مقالات و پیش‌نویس‌ها به یک دیتابیس Postgres نیاز دارد — سرویس رایگان Supabase کافی است:

  1. به supabase.com بروید و با گیت‌هاب یا ایمیل ثبت‌نام کنید
  2. New project → نام دلخواه → رمز دیتابیس (لازم نیست جایی یادداشت کنید) → منطقه نزدیک به سرور اجرا (مثلاً Frankfurt)
  3. بعد از آماده‌شدن پروژه: Project Settings → API
  4. دو مقدار را کپی کنید:
    • Project URL → همان SUPABASE_URL
    • service_role secret → همان SUPABASE_KEY (دکمه Reveal را بزنید)
پنل Supabase — Settings → API
supabase.com/dashboard
Project URL  →  https://xbko…kza.supabase.co
service_role secret  →  eyJhbGciOiJIUzI1NiIs… [Reveal]
anon public → ❌ استفاده نکنید
⚠️
حتماً کلید service_role — نه anon. کلید service_role دسترسی کامل دارد و فقط باید سمت سرور (روی هاست بات) بماند؛ هرگز داخل گیت یا کد سمت کاربر قرار نگیرد.

اجرای جداول SQL

⏱ ۳ دقیقه

در پنل Supabase، از منوی چپ SQL Editor → New query را باز کنید و ۱۰ فایل پوشه sql/ ریپو را به‌ترتیب اجرا کنید:

ترتیب اجرا در SQL Editor
SQL Editor

02_ai_images_footer.sql
03_discussion_fulltext.sql
04_digest.sql
05_provider_keys.sql
06_social_sources.sql
07_filters.sql
08_user_feedback.sql
09_admin_notes.sql
10_custom_providers.sql ✓

فایل‌ها را از پوشه sql در گیت‌هاب باز کنید، محتوایشان را کپی و در SQL Editor پیست کنید و دکمه Run را بزنید — به‌ترتیب، یکی‌یکی.

💡
اگر بعداً پیام خطای «column does not exist» دیدید، یعنی یکی از فایل‌ها اجرا نشده — همین لیست را دوباره چک کنید.

گرفتن کلید هوش مصنوعی

⏱ ۵ دقیقه

بات برای بازنویسی/ترجمه اخبار به پست فارسی، به یک مدل زبانی با رابط OpenAI-compatible نیاز دارد. فقط یکی از گزینه‌ها کافی است:

🔵 DeepSeek پیشنهادی

ثبت‌نام در platform.deepseek.com → ساخت API Key → شارژ حداقلی. مدل «deepseek-chat» فارسی خوبی می‌نویسد.

🟣 Dahl

اگر از سرویس‌های واسط استفاده می‌کنید: AI_KEYS=dahl=… و DAHL_BASE_URL را طبق .env.example تنظیم کنید.

⚙️ هر Provider سازگار

XKIRO، Inception، Vyce یا هر سرویس OpenAI-compatible دیگر — با زنجیره fallback پشتیبانی می‌شوند.

کلید را در متغیر AI_KEYS می‌گذارید (چند کلید هم پشتیبانی می‌شود، جداکننده ;):

# یک کلید:
AI_KEYS=deepseek=sk-xxxxxxxx

# چند کلید / چند سرویس (چرخش + fallback):
AI_KEYS=deepseek=sk-aaa;dahl=sk-bbb
💡
اگر کلید هوش مصنوعی نداشته باشید بات اجرا می‌شود اما به‌جای پست AI، متن خام خبر را می‌فرستد. با دستور /aicheck داخل بات می‌توانید سلامت همه کلیدها را تست کنید.

نصب و اجرای بات

⏱ ۵ دقیقه

نیازمندی‌ها: Python 3.10+ و git. در ترمینال:

# ۱) دانلود پروژه
git clone https://github.com/mohsen-niksirat/News-Channel-Bot.git
cd News-Channel-Bot

# ۲) محیط مجازی + نصب وابستگی‌ها
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# لینوکس/مک:
source .venv/bin/activate

pip install -r requirements.txt

# ۳) ساخت فایل تنظیمات
cp .env.example .env

فایل .env را باز کنید و ۴ مقدار اجباری را پر کنید:

BOT_TOKEN=توکن BotFather از مرحله ۱
SUPABASE_URL=آدرس پروژه از مرحله ۲
SUPABASE_KEY=کلید service_role از مرحله ۲
AI_KEYS=deepseek=کلید مرحله ۴
⚠️
فایل .env در .gitignore است و هرگز به گیت پوش نمی‌شود — پس می‌توانید با خیال راحت مقادیر واقعی را داخلش بنویسید.

اجرای تستی:

python main.py

اگر لاگ اتصال را دیدید، به بات در تلگرام /start بدهید — باید منوی فارسی جواب بدهد. ✋ فعلاً با Ctrl+C متوقفش کنید؛ در مرحله بعد کانال را وصل می‌کنیم.

اتصال کانال و انتشار اولین پست

⏱ ۵ دقیقه
  1. بات را به‌عنوان ادمین کانال اضافه کنید (دسترسی «حذف پیام‌ها» حتماً فعال باشد)
  2. بات را دوباره اجرا کنید: python main.py
  3. در چت بات: /channel → آیدی کانال را بفرستید: @mychannel
  4. /auto off → برای شروع، بررسی دستی (پیشنهادی)
  5. /scan → بات فیدها را می‌خواند و پیش‌نویس می‌سازد
  6. /review → پیش‌نویس‌ها را با دکمه‌ها بررسی کنید

استقرار دائمی (VPS / Docker / Railway)

⏱ ۱۰ دقیقه

بات با long polling کار می‌کند — نه پورت می‌خواهد نه دامنه؛ فقط باید پروسه‌اش همیشه روشن باشد. اجرای روی کامپیوتر شخصی دائمی نیست؛ یکی از این سه روش را انتخاب کنید:

🖥 VPS + systemd ارزان‌ترین

سرور اوبونتو ~۵$ — سرویس systemd با ری‌استارت خودکار. راهنمای کامل: docs/DEPLOY.md

🐳 Docker

با فایل‌های آماده در ریپو: docker compose up -d --build و تمام.

🚄 Railway ساده‌ترین

بدون سرور: ریپو را وصل کنید، Start Command = python main.py، متغیرها را در تب Variables بگذارید.

نمونه سرویس systemd (/etc/systemd/system/newschannelbot.service):

[Unit]
Description=NewsChannelBot
After=network-online.target

[Service]
User=newsbot
WorkingDirectory=/opt/newschannelbot
EnvironmentFile=/opt/newschannelbot/.env
ExecStart=/opt/newschannelbot/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
sudo systemctl enable --now newschannelbot
journalctl -u newschannelbot -f   # لاگ زنده
💡
بعد از استقرار دائمی دیگر نیازی به کامپیوتر روشن نیست — بات ۲۴/۷ فیدها را اسکن و کانال را به‌روز نگه می‌دارد. مانیتورینگ: /adminstats و لاگ‌های سرور.
