ساخت بات در تلگرام (BotFather)Create the bot on Telegram (BotFather)

⏱ ۵ دقیقه5 min

بات‌های تلگرام همه از طریق ربات رسمی BotFather ساخته می‌شوند: All Telegram bots are created through the official BotFather bot:

  1. در تلگرام به @BotFather پیام بدهید
  2. دستور /newbot را بفرستید
  3. یک نام نمایشی برای بات انتخاب کنید (مثلاً «بات خبر من»)
  4. یک یوزرنیم یکتا انتخاب کنید که حتماً به bot ختم شود (مثلاً my_news_helper_bot)
  1. Message @BotFather on Telegram
  2. Send the /newbot command
  3. Pick a display name (e.g. "My News Bot")
  4. Pick a unique username that must end in bot (e.g. my_news_helper_bot)

Register the bot commands via /setcommands. A ready-made list lives in BOTCOMMANDS.txt in the repo — just paste it to BotFather to enable the users' command menu.

ساخت دیتابیس در SupabaseCreate the database on Supabase

⏱ ۵ دقیقه5 min

بات برای ذخیره کاربران، منابع خبری، مقالات و پیش‌نویس‌ها به یک دیتابیس Postgres نیاز دارد — سرویس رایگان Supabase کافی است: The bot stores users, news sources, articles and drafts in a Postgres database — the free Supabase tier is enough:

  1. به supabase.com بروید و با گیت‌هاب یا ایمیل ثبت‌نام کنید
  2. New project → نام دلخواه → رمز دیتابیس (لازم نیست جایی یادداشت کنید) → منطقه نزدیک به سرور اجرا (مثلاً Frankfurt)
  3. بعد از آماده‌شدن پروژه: Project Settings → API
  4. دو مقدار را کپی کنید:
    • Project URL → همان SUPABASE_URL
    • service_role secret → همان SUPABASE_KEY (دکمه Reveal را بزنید)
  1. Go to supabase.com and sign up with GitHub or email
  2. New project → pick a name → database password (no need to memorize) → a region close to your bot's server (e.g. Frankfurt)
  3. Once ready: Project Settings → API
  4. Copy two values:
    • Project URL → this is your SUPABASE_URL
    • service_role secret → this is your SUPABASE_KEY (click Reveal)

⚠️
حتماً کلید service_role — نه anonUse the service_role key — not anon کلید service_role دسترسی کامل دارد و فقط باید سمت سرور (روی هاست بات) بماند؛ هرگز داخل گیت یا کد سمت کاربر قرار نگیرد. The service_role key has full access and must stay server-side (on the bot host) only; never put it in git or client code.

گرفتن کلید هوش مصنوعیGet an AI key

⏱ ۵ دقیقه5 min

بات برای بازنویسی/ترجمه اخبار به پست فارسی، به یک مدل زبانی با رابط OpenAI-compatible نیاز دارد. فقط یکی از گزینه‌ها کافی است: To rewrite/translate news into Persian posts, the bot needs an OpenAI-compatible LLM provider. Any one of these is enough:

🔵 DeepSeek پیشنهادیrecommended

ثبت‌نام در platform.deepseek.com → ساخت API Key → شارژ حداقلی. مدل «deepseek-chat» فارسی خوبی می‌نویسد.Sign up at platform.deepseek.com → create an API key → minimal top-up. The deepseek-chat model writes good Persian.

🟣 Dahl

اگر از سرویس‌های واسط استفاده می‌کنید: AI_KEYS=dahl=… و DAHL_BASE_URL را طبق .env.example تنظیم کنید.If you use relay services: set AI_KEYS=dahl=… and DAHL_BASE_URL per .env.example.

⚙️ هر Provider سازگارAny compatible provider

XKIRO، Inception، Vyce یا هر سرویس OpenAI-compatible دیگر — با زنجیره fallback پشتیبانی می‌شوند.XKIRO, Inception, Vyce or any other OpenAI-compatible service — all supported via the fallback chain.

کلید را در متغیر AI_KEYS می‌گذارید (چند کلید هم پشتیبانی می‌شود، جداکننده ;): Put the key in the AI_KEYS variable (multiple keys supported, separated by ;): 

# one key:
AI_KEYS=deepseek=sk-xxxxxxxx

# multiple keys / providers (rotation + fallback):
AI_KEYS=deepseek=sk-aaa;dahl=sk-bbb
💡
اگر کلید هوش مصنوعی نداشته باشید بات اجرا می‌شود اما به‌جای پست AI، متن خام خبر را می‌فرستد. با دستور /aicheck داخل بات می‌توانید سلامت همه کلیدها را تست کنید. Without an AI key the bot still runs but posts raw news text instead of AI-written posts. Use /aicheck inside the bot to test all keys.

🤖

Hand it to an agent! این مرحله و همه مراحل بعدی فنی را می‌توانید به ایجنت‌های هوشمند (Freebuff، OpenCode، Xiaomi MiMo AI و…) بسپارید: فقط آدرس ریپو و ۴ مقدار کلیدی را بدهید؛ کلون، نصب، ساخت .env و اجرا را خودشان انجام می‌دهند. شما فقط در Supabase و Deployka ثبت‌نام کنید (مرحله ۲ و ۷). You can delegate this and every later technical step to AI agents (Freebuff, OpenCode, Xiaomi MiMo AI, …): just give them the repo URL and the 4 key values; they clone, install, create .env and run everything. You only sign up on Supabase and Deployka (steps 2 & 7).

نیازمندی‌ها: Python 3.10+ و git. در ترمینال: Requirements: Python 3.10+ and git. In a terminal: 

# 1) clone the project
git clone https://github.com/mohsen-niksirat/News-Channel-Bot.git
cd News-Channel-Bot

# 2) virtual env + dependencies
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

# 3) create the config file
cp .env.example .env

فایل .env را باز کنید و ۴ مقدار اجباری را پر کنید: Open .env and fill in the 4 required values: 

BOT_TOKEN=BotFather token (step 1)
SUPABASE_URL=project URL (step 2)
SUPABASE_KEY=service_role key (step 2)
AI_KEYS=deepseek=AI key (step 4)
⚠️
فایل .env در .gitignore است و هرگز به گیت پوش نمی‌شود — پس می‌توانید با خیال راحت مقادیر واقعی را داخلش بنویسید. .env is in .gitignore and never gets pushed to git — so it's safe to put real values inside it.

اجرای تستی: Test run: 

python main.py

اگر لاگ اتصال را دیدید، به بات در تلگرام /start بدهید — باید منوی فارسی جواب بدهد. ✋ فعلاً با Ctrl+C متوقفش کنید؛ در مرحله بعد کانال را وصل می‌کنیم. If you see the connection log, send /start to the bot on Telegram — it should reply with the menu. ✋ Stop it with Ctrl+C for now; we'll connect the channel next.

  3. In the bot chat: /channel → send your channel: @mychannel
  4. /auto off → start with manual review (recommended)
  5. /scan → the bot reads feeds and creates drafts
  6. /review → check drafts with the buttons

استقرار دائمی (Deployka / VPS / Docker)Permanent deployment (Deployka / VPS / Docker)

⏱ ۱۰ دقیقه10 min

بات با long polling کار می‌کند — نه پورت می‌خواهد نه دامنه؛ فقط باید پروسه‌اش همیشه روشن باشد. اجرای روی کامپیوتر شخصی دائمی نیست؛ یکی از این روش‌ها را انتخاب کنید: The bot uses long polling — no inbound ports, no domain; the process just has to stay alive. A personal computer isn't always-on; pick one of these:

🚀 Deployka پیشنهادی — همین راهنما با آن تست شدهrecommended — tested here

deployka.dev — پنل ساده، بدون سرور. نسخه رایگان ۱۲۸ مگابایت رم می‌دهد که برای این بات کافی است. کافیست سرویس Python بسازید، ریپو را وصل کنید، ۴ متغیر محیطی را وارد کنید و Start Command را python main.py بگذارید. deployka.dev — simple panel, no server. The free tier gives 128 MB of RAM, enough for this bot. Create a Python service, connect the repo, add the 4 env vars, and set Start Command to python main.py.

🐳 Docker / Railway

Docker با فایل‌های آماده: docker compose up -d --build. Railway: ریپو را وصل کنید و متغیرها را در تب Variables بگذارید.Docker with ready-made files: docker compose up -d --build. Railway: connect the repo and set variables in the Variables tab.

در Deployka فقط این ۴ متغیر را در بخش Environment وارد کنید: On Deployka, enter just these 4 variables in the Environment section: 

BOT_TOKEN=(step 1)
SUPABASE_URL=(step 2)
SUPABASE_KEY=(step 2)
AI_KEYS=deepseek=(step 4)

نمونه سرویس systemd برای VPS (/etc/systemd/system/newschannelbot.service): Sample systemd service for a VPS (/etc/systemd/system/newschannelbot.service): 

[Unit]
Description=NewsChannelBot
After=network-online.target

[Service]
User=newsbot
WorkingDirectory=/opt/newschannelbot
EnvironmentFile=/opt/newschannelbot/.env
ExecStart=/opt/newschannelbot/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
sudo systemctl enable --now newschannelbot
journalctl -u newschannelbot -f   # live logs
